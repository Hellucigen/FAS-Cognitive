# EXPERIMENT_VALIDITY_MATRIX.md — 既有实验有效性裁决
**日期**: 2026-09-30(本审计独立复核;50% = 论文 + 本审计对现有实验样本/记录的重新评估)
**原则(45 章规格)**: 激活成功绝不报为行为成功;四个证据层级(L1 原始留存 / L2 机制指标 / L3 行为指标 / 论文主张);装配无效 = 实验无效,结论不成立;每个实验给出可信度与"能支持的说法"上限。

---

## 一、层级标尺
- **L1 原始证据**: run 归档/图快照/log 留存,程序化提取
- **L2 机制级**: 图指标(节点/边/激活/方向)上的可测差异
- **L3 行为级**: 达成/行动选择/tick 等行为指标的差异
- **论文主张**: 论文从实验得出的结论措辞

## 五、总体有效性结论
1. **论文的实验记录质量高**:自我宣告两次装配事故(C34 v1、早期消融矩阵扩散未接线),全部否定结果与边界(闭包遮蔽、-扩散更快、Hebb 亚阈、路由校正后不显著)与正面结果并列 —— 未发现"把激活成功报为行为成功"的越级。
2. **零实验被本审计判为总体无效**;唯一 INVALID 是 C34 v1,且论文已自我宣告。
3. **边界纪律**:S4/D(事件框架)与 S3/C(账本)是仅有的 L3 行为证据,均明确限定在"沙箱装配/实验层装配"内;生产默认关(事件框架)的含义已写入 FINAL_DIAGNOSIS。
4. 对"路由性能/激活质量在行为层面优于扩散"的断言:**无单一实验支持**(U5);任何行为级优良性结论须维持"方向性/机制级"表述。
