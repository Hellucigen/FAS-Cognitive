## 一、语言在 FAS 中的位置

FAS 的认知内容是图结构（实体/事件/情绪/行为/倾向）与激活分布。语言以三种形态与图发生关系：

```
        【语言输入】                 【语言输出】
自然语言文本                    自然语言文本
    │                              ↑
    ▼                              │
┌─────────────────────────────────────────────┐
│  语言层（Language Layer）                     │
│  LLM 受约束的结构归纳  +  词汇化短语判定        │
│  输入语言 → 图结构草案          图状态草案 → 输出语言 │
└─────────────────────────────────────────────┘
    │                              ↑
    ▼                              │
┌─────────────────────────────────────────────┐
│  认知层（图谱动力学）                          │
│  注入 → 扩散 → 竞争 → 行为裁决 → 回写          │
│  这里没有语言，只有节点、边、激活               │
└─────────────────────────────────────────────┘
```

语言层的全部产出都是**图结构草案**（节点/边/事件框架/行为候选提名/分类标签），全部输入都是**图状态**（Top-k、焦点事件、情绪、倾向、行为裁决结果）。语言层没有决策权——它提议，图裁决；图决定，它转译。

## 二、边界的精确表述

用户命题：**"原子化的是认知表示，不是自然语言。"**

这意味着两个对称的禁令：

1. **禁止把语言强行离散成图**：自然语言的词、词缀、语气词、句式**不是**节点。"终于"不是节点（它是情绪/显著性的证据），"把…跑起来"不是节点（"跑起来"的整体事件才是），疑问句式不是节点（dialogue_act 分类才是它的认知表示）。图谱不需要也不应该承担完整的自然语言解析——句法分析只在语言层发生，且只在服务于结构归纳时发生（复合短语判定就是这么做的：ATT 依存→配价检验→判定，产物是"这个短语指什么"的图结构，不是句法树）。
2. **禁止让图生成语言**：图的职责终止于"决定说什么"（行为裁决+内容要点=激活焦点结构），"怎么说"（词汇选择、句法组织、语气）是语言层（LLM）的转译职能。要求图产出语法正确的句子，等于让认知层干界面的活。

一句话版本：**图里存的是"认识了什么"，不是"话是怎么说的"；语言层做的全部工作是两个方向的转译。**

### 边界测试判据（用于审计任何新机制）

- 一个语言成分（词/短语/句式）要不要入图？→ 问：它是认知上原子的吗（有独立指称/独立情绪值/独立行为倾向）？不是 → 它只作为证据出现在属性与边的 reason 里。
- 一段话要不要 LLM 处理？→ 问：这是结构归纳（抽取/分类/提名）还是认知决策（做什么/信什么）？后者 → 不允许 LLM 单独决定，产出必须是供图裁决的候选。

## 三、语言系统职责清单

### 该承担（Language Layer 职责）

| 职能 | 现状 | 说明 |
|---|---|---|
| 语言→图结构归纳（NLP_PARSE/MEMORY_EXTRACT） | ✅ 已合规 | LLM 提议节点/边/事件框架，代码校验入图——论文 §8.8.1 的标准形态 |
| 认知分类提名（illoc/da/expectation/goals） | ⚠️ 改造中 | 提名合法，但下游必须把提名变成激活信号，不能变成 if-else 豁免（unwanted §2.2/§5.2） |
| 词汇化/组构性判定（compound phrase） | ✅ 合规且应扩展 | 判定一次、沉淀复用；应成为语言层常规部件（emergent §2.3） |
| 图状态→语言转译（回答生成） | ⚠️ 需重新定位 | 生成的内容要点与取向来自图（Top-k 结构+行为裁决+焦点事件+情绪），LLM 只负责把这份"发言提纲"转成自然语言。"发言提纲"的具体化见 §四 第 10 步 |
| 代词/时间指代消解 | ✅ 已合规 | 模板规则+焦点事件指针上下文——典型的"服务于结构归纳的解析" |

### 不该承担（越界即违规）

| 禁止事项 | 当前违规点 |
|---|---|
| LLM 直接决定要不要回答 | 当前：部分豁免通道让 web_results/期待度直接强制生成（unwanted §2.2）→ 改为行为竞争 |
| LLM 直接决定回应的立场/取向 | 当前：ANSWER_GENERATE 拿到 Top-k 后自由发挥，"不编造图谱外信息"约束力弱 → 改为图给出发言提纲（内容要点=激活结构+焦点事件+情绪+行为） |
| 图内建语言成分节点（复合词/句式/语气词） | 当前基本合规（"太苦的咖啡"拆分规则已入 MEMORY_EXTRACT），需守住不回退 |
| 用 prompt 人设替代图状态决定风格 | 当前：FAS_IDENTITY 静态人设（unwanted §5.1）→ 改为自我状态快照注入 |

## 四、边界测试："我终于把 FAS 跑起来了。"

> 提纲十要求：理解 → 事件 → 说话者 → 情绪意义 → Self 激活 → 记忆 → 预测误差/显著性 → 社会激活 → 回应决策 → 自然语言生成。全程标注：哪步是语言层、哪步是图、LLM 的产出物是什么。**判定标准：最终答案不由 LLM 直接决定。**

**输入**：`我终于把 FAS 跑起来了。`

### 第 1 步 · 语言解析（语言层）

- NLP_PARSE LLM 产出：nodes=[用户, Fascinator, FAS]（"FAS"经别名归并入 Fascinator）；edges=[用户-运行→Fascinator]；dialogue_act=sharing，illocutionary_act=assertive（含表达成分），response_expectation=medium，reply_goals=[acknowledge, continue_conversation]。
- "终于"**不建节点**——它作为 edge.reason 证据（"长期努力后达成"）传递给情绪步骤。这是 §二 判据 1 的应用：副词没有独立指称。
- **LLM 产出物 = 结构草案**。合规。

### 第 2 步 · 事件框架形成（语言层提名，图落地）

- MEMORY_EXTRACT（下一阶段或同轮）产出事件：`把FAS跑起来`（episodic，发生时间=今天，参与者=用户，涉及=Fascinator），附稳定属性边：用户-使用→Fascinator。
- "终于"在这里转化为事件的情绪证据 → 引发=成就感/如释重负 边。

### 第 3 步 · 注入与扩散（图）

- 初始激活：用户、Fascinator、事件节点、成就感。
- Fascinator 是 self 空间枢纽 → **自指事件**：事件涉及 Fascinator 本身，激活沿 self 空间传播规则（衰减少）进入 Self 子图。Self 节点强激活——**这次对话在 FAS 眼里是"关于我自己的事件"**，这不是 prompt 告诉它的，是图结构（事件-涉及→Fascinator-Fascinator∈self）决定的。

### 第 4 步 · 记忆回响（图）

- 共享实体 用户 → 历史事件（远方之行、喝奶茶、Minecraft 教学群）沿实体边被再激活。
- 挖矿/奶茶 等语义邻居轻度激活。
- 结果：Top-k 里既有当下事件又有历史经验——回应的素材是**联合激活的产物**，不是 LLM 从原文猜的。

### 第 5 步 · 预测误差 / 显著性（图，V2 新增职能）

- 预期：用户近 110 轮的话题分布（Minecraft/生活/学术）构成"用户-话题"习得边权。**FAS 作为话题本身**是低频事件 → novelty 信号高（可用两种图内实现：Fascinator 节点的激活历史方差、或事件与既有事件结构的 embedding 距离）。
- "终于"注入的成就感情绪节点激活 → 情绪调制（V2 参数节点化后：正向情绪→β 增益↑、注意容量 k↑——这次事件比寻常闲聊扩散得更广）。
- **注意**：这一步在当前代码中缺失（情绪是装饰性的，novelty 无实现）——它是 V2 的核心新增，也是本测试句能否产生"非平凡回应"的关键。

### 第 6 步 · 社会激活 / 行为竞争（图）

- 行为候选节点获得初始激活：
  - 行为:回应 ← sharing × medium 期待（基础增益）；
  - 行为:追问 ← novelty 高（FAS 自己被跑起来了，它确实想了解"感觉怎么样"——好奇=未知信号+自指事件）；
  - 行为:确认 ← reply_goals[acknowledge] 提名增益；
  - 行为:沉默 ← 低（期待 medium 以上压制）。
- disposition 习得偏置叠加（当前为零数据，竞争主要靠情境增益——这正好是诚实的发育状态）。
- **裁决**：θ_action 阈值下，本句的正确预期胜出者是 行为:回应（内容含确认+基于 Top-k 的联想）或 行为:追问。无论哪个胜出，**决定者是激活分布**。

### 第 7 步 · 发言提纲组装（图 → 语言层）

图输出给语言层的不是"自由发挥"许可，是一份结构化提纲：
```
行为裁决: 回应（次要: 追问）
内容要点（按激活序）: [把FAS跑起来(事件,今天)] [用户] [成就感] [Fascinator(self)]
焦点事件: 把FAS跑起来
情绪状态: 成就感(自指) + 用户侧积极
习得倾向: (无 stable 倾向——诚实标注)
历史可联想: [Minecraft教学经历] [远方之行]
```

### 第 8 步 · 语言生成（语言层）

- LLM 把提纲转译为自然语言。它决定措辞与句法，**不决定说什么**——提纲里没有"用户大学在某地"这种未经激活的内容（即使模型参数里知道，也不许编造图谱外信息——这条约束现在存在但弱，配合发言提纲后成为硬约束：要点清单之外的实体不应出现在回答里）。
- 合格输出的例子："跑起来了就好。折腾了这么久——是卡在哪一步了吗？"（回应+基于成就感的确认+历史"折腾"证据的联想+追问候选）
- **判定：最终答案由图决定（行为+要点+焦点），LLM 只做措辞。**

### 全程越界检查

| 步骤 | 若越界会发生什么 |
|---|---|
| 1 | "终于"若被建成节点 → 图里多一个无指称垃圾节点，FAISS 与扩散被污染 |
| 3 | 若无 self 空间传播规则 → 自指事件与普通事件无差别，FAS 对"关于自己的事"没有特殊反应 |
| 5 | 若无 novelty/情绪调制 → 对"重大事件"与"随口一提"给出同等强度的回应（机械回复的根源之一） |
| 6 | 若 LLM 直接决定 → 回答内容取决于模型当天的心情与训练分布，FAS 的"个性"漂移不可追溯 |
| 8 | 若提纲没有硬约束 → LLM 用参数知识补全（幻觉入口重新打开） |

## 五、当前实现与边界的差距（汇总）

1. **发言提纲缺失**（§四 第 7 步）：answer_question 的 prompt 是"自由生成+弱约束"，不是"提纲转译"。这是 LLM 实质成为决策中枢的最后一块地基，V2 必拆。
2. **情绪/显著性调制缺失**（第 5 步）：论文 §3.3 p(t) 参数公式未实现，重大事件与闲聊同等对待。
3. **行为竞争未统一**（第 6 步）：三套候选系统并存（unwanted §6），裁决由豁免通道堆叠。
4. **词汇化判定接入孤立**（§三）：compound_phrase 只服务好奇心，应前置为语言层常规部件。
5. **静态人设**（§三）：风格锚定在 prompt 而非图状态。

## 六、语言能力的生长路径

"越来越少的硬编码规则产生越来越丰富的行为"在语言层的具体形态：

1. **词汇化短语表随使用增长**（已有，扩展接入点后加速）——每判定一个新短语，系统对 LLM 解析的依赖永久减一；
2. **行为-情境边随经历强化**（disposition 通路修复后）——表达方式从 prompt 人设迁移到习得边权；
3. **"用户-话题"边随对话积累**（Hebbian 落地后）——预测误差的预期基线自动更新，无需人工维护话题列表；
4. **回应用词的稳定性来自图**：同一情境下 Top-k 结构相似 → 提纲相似 → 表达自然连贯——"说话像不像同一个人"由图状态的连贯性保证，不再依赖模型的一致性。

最终形态：语言层只保留两类常驻规则——结构归纳的输出格式约束，与短语判定的沉淀机制。其余一切（风格、立场、好奇方向、回应习惯）都是图状态，从经历中长出来。
