# FAS 认知架构 V2（fas_cognitive_architecture_v2.md）

> 认知架构重评估 · 文档 6/7
> 回答重评估提纲问题 (8)(9)(10)(11)(12)（图/LLM/自学/永不入图/永不固定规则），并给出 V2 的机制设计。
> V2 的定义：不是新功能列表，而是**把行为决策还给激活竞争、把学习还给图动力学**之后的 FAS。
> 一切设计以论文原始机制为基准（fas_original_vision.md §二），以现状审计为起点（audit/unwanted 两文档）。

---

## 一、V2 认知循环（总纲）

```
① 感知/语言输入
     │  语言层：结构归纳（节点/边/事件/分类提名）——无决策权
     ▼
② 激活注入（全部以信号形式，无豁免通道）
   实体/事件注入 + 分类提名→行为节点增益 + 情绪共振 + FAISS 相似
     ▼
③ 扩散（参数由参数节点 p(t) 提供，受情绪/动机调制）
   多阶段 API：阶段注入→扩散→再注入→再扩散（替代 config 体操）
     ▼
④ 行为竞争裁决（V2 核心：唯一裁决点）
   行为节点（回应/追问/沉默/搜索/记录/共情/…）竞争
   激活（来自②③）× 习得偏置（disposition 边）× θ_action（参数节点）
   胜者进入执行；无胜者 = 真沉默
     ▼
⑤ 执行（语言层转译"发言提纲"→文本；或搜索/记录等程序性执行）
     ▼
⑥ 回写（全部结构化，全部进图）
   事件/新知识 → 巩固通路（δ 增量累积）
   行为→结果 → disposition 边权（outcome 信号升级）
   共激活 → Hebbian w += ε·a·a
   活动痕迹 → 日志（不入图）
     ▼
⑦ 离线整合（反思：产出必须落到 激活/倾向/边权；soft forgetting 扫描）
     └──────────→ 回到 ①（图的当前形态即下一轮的先验）
```

与现状的本质差别一句话：**现状是"代码管线调用图当存储"，V2 是"图动力学产生行为，代码只当物理引擎"。**

## 二、Graph 应该承担什么（提纲八）

| 承担 | 具体内容 | 论文依据 |
|---|---|---|
| 全部认知状态 | 知识/经历/情绪/倾向/目标/能力/参数/活跃好奇问题——一律节点+边+激活，无图外认知状态（unwanted §3 全部修复） | §3 |
| 注意与焦点 | 激活扩散+Top-k；k/λ/θ 由参数节点调制 | §5.1 |
| 行为决策 | 行为节点竞争，θ_action 裁决；豁免通道清零 | §8.5 |
| 学习 | Hebbian 共激活、重复验证 δ、disposition 边权、反思产出——全部是图结构/权重的持续更新 | §6 |
| 遗忘 | soft forgetting：last_access 驱动的权重衰减（数据保留，可及性降低） | §6.2 反面 |
| 情绪 | 情绪节点激活 → p(t) 调制扩散参数（不是 prompt 语气词） | §3.3 |
| 自我 | Self 子图 = 身份/倾向/能力/当前焦点事件指针；"我是谁"从图状态生成 | §3.3 |
| 时间感 | 焦点事件指针 + 时间锚 + 事件层级——心理时间线 | §3.4 |

## 三、LLM 应该承担什么（提纲九）

| 承担 | 禁止 |
|---|---|
| 语言→图的结构归纳（唯一的知识入口转译者） | 直接决定要不要回答（行为竞争的事） |
| 认知分类提名（illoc/da/期待/目标→激活信号） | 直接决定回答立场（发言提纲的事） |
| 词汇化/组构性判定（沉淀复用） | 直接决定好奇什么（未知信号+习得边的事） |
| 发言提纲→自然语言的转译 | 直接决定"我是谁"（Self 子图的事） |
| 反思分析与倾向提名（候选，数值代码算） | 用参数知识补全提纲外内容（幻觉入口） |

判据（audit §3.1 已立）：LLM 的每个产出都必须是**供图裁决的候选或供代码校验的结构**；产出即终局的 LLM 调用即违规。

## 四、哪些能力由 FAS 自己逐渐学出来（提纲十）

| 能力 | 学习通路 | 现状 |
|---|---|---|
| 表达风格/人格 | 经历→行为→结果→disposition 边权（candidate→stable） | 机制在、通路断（9 天零产出），P0 修通路 |
| 好奇的方向 | 未知信号+共激活强化（Hebbian）自然形成"爱问什么" | 剧本边替代了学习，P0 删剧本 |
| 话题预期（预测误差基线） | "用户-话题"边随对话强化（Hebbian 同一机制） | 无实现，P1 |
| 常用联想路径 | Hebbian w += ε·a·a——常用路径自动变宽 | 论文核心学习机制从未实现，P1 最高价值 |
| 语言理解广度 | 词汇化短语表随使用积累 | 已在长，扩展接入点即可 |
| 对用户的认知模型 | 用户为中心的语义子图自然增厚（共享实体耦合） | 已在发生（事件框架红利） |
| 自我认知 | 反思产出→Self 子图；能力边界随真实执行更新 | 机制在，产出落地弱 |
| **不学的**（永远 prompt/代码） | JSON 输出格式、白名单校验、θ 裁决机制本身、物理引擎（队列/锁/持久化） | — |

## 五、哪些事情永远不应该交给图谱（提纲十一）

1. **自然语言本身**：句子、句式、语气词不入图（原子化的是认知表示——language_arch §二）；图不做完整 NL 解析/生成。
2. **活动流水**：每轮回答/思考的原始文本不入图（52 个回答记录的教训）——痕迹归日志，图只存影响未来的结构。
3. **瞬时计算中间量**：扩散的 Δa 累积、FAISS 距离矩阵、正则匹配过程——物理引擎的工作过程不是认知状态。
4. **数据结构与索引**：别名表（运行时部分）、嵌入向量、rename_map、短语表（语言资源，非认知状态）——它们服务于图，不是图的成员。
5. **裁决机制本身**：θ_action 阈值"如何比较"是物理定律，不是认知内容；比较的**输入**（激活、偏置）在图，比较器在代码。
6. **可追溯性日志**：演化日志、chat_log——记录认知活动的镜子，不是认知活动（这两个模块的图外定位是唯一正当的）。

## 六、哪些事情永远不由固定规则决定（提纲十二）

1. **要不要回应/以什么行为回应**（行为竞争裁决，除非物理性守恒约束）；
2. **好奇什么**（未知信号+习得方向，永不写剧本链）；
3. **人格与表达倾向**（经历强化，永不写风格规则/prompt 人设）;
4. **什么值得记**（重要性+情绪+重复的图信号，永不"全部记录"）;
5. **对输入的情绪反应**（共振+图内情绪结构，永不词表枚举——词表只可兜底）;
6. **说话的具体内容立场**（发言提纲=激活结构，永不自由生成）;
7. **遗忘什么**（可及性衰减由激活历史驱动，永不人工挑选）。

固定规则永远只允许出现在三处：**输入校验**（白名单/格式）、**物理守恒**（能量钳制/fire-once/队列顺序）、**发育期脚手架**（明确标注降级条件的临时兜底，如正则意图词——LLM 不可用时的最低保障，且随 disposition 证据积累降低权重）。

## 七、V2 机制设计

### 7.1 行为竞争统一（替换三套候选系统 + 全部豁免通道）

- 行为节点集：BEHAVIORS 9 词表起步（回应/追问/确认/详述/共情/分享/延续/收尾/沉默），可扩展；
- 初始激活来源（全部是信号注入，非分支）：分类提名（reply_goals→对应行为节点 +gain）、期待度（回应 +gain）、未知信号（追问/搜索 +gain）、情绪强度（共情/分享 +gain）、novelty（追问 +gain）；
- 偏置来源：disposition 情境-行为边（习得偏置，直接加到扩散注入）；
- 裁决：θ_action（参数节点）+ 优势度；代码只做执行；
- 程序性行动队列（网络搜索/WASD/记录）保留原队列机制，行为节点激活作为入队条件——两条通路合一（行为:搜索 胜出=网络搜索节点获注入激活→超 θ 入队执行）。

### 7.2 参数节点化（论文 §3.3 p(t) 公式落地）

```
p(t) = clip(p0 + Σ αm,p · a(m,t), pmin, pmax)
```
- 参数节点：k_top / λ / β / θ_action / Dmax，存于 self 空间；
- 调制源：情绪节点（成就感/焦虑/无聊…）与动机节点（好奇心/社交欲），α 手工设定一次（这是"物理常数"不是行为规则）；
- **论文 §8.9 第三条预警的落实**：pmin/pmax 上下界 + 变化率平滑（每轮限制 Δp）+ 异常值检测日志——三者齐备后才允许调制生效。

### 7.3 Hebbian 共激活强化（论文 §6.2 原式）

```
w(u,v) += ε · a(u,t) · a(v,t)，ε = 1e-5 ~ 1e-4
```
- 每轮扩散结束后扫描 Top-k 内实边执行；
- **§8.9 第二条预警（路径锁定）的落实**：设 w 上限（如 1.0）+ 弱化通道（无共激活的边按极小速率衰减，如每 100 轮 -1e-3），保证可塑性与稳定性平衡；
- 排除 infra/记录类节点，只作用于 declarative/cognitive 语义边。

### 7.4 发言提纲（语言生成重定位）

- 行为裁决后，图组装结构化提纲：行为+内容要点（Top-k 压缩）+焦点事件+情绪状态+倾向标注（含"无 stable 倾向"的诚实标注）；
- ANSWER_GENERATE 改为提纲转译任务：要点外实体禁入（硬校验：回答文本经 embedding 与提纲要点比对，漂移即重试）；
- 无行为胜出 → 真沉默，不生成兜底句。

### 7.5 好奇心图内化

- 活跃好奇问题 = curiosity 节点（问题文本/目标/提出轮次 属性）；
- 未知信号（UnknownObject 激活/稀疏邻域/FAISS miss）→ 未知信息 节点激活 → 行为:追问/网络搜索 竞争（§7.1）；
- resolve = 回答命中目标节点 → 好奇节点激活衰减 + 目标节点获得巩固；
- CURIOSITY_CHAIN 删除，_current_curiosity dict 删除。

### 7.6 反思产出落地（反思≠日志摘要）

- 反思产出的每个候选必须落到具体图操作：belief/preference→Self 子图（仅 Fascinator 视角，unwanted §3.5）；candidate_disposition→pair 证据；new_knowledge→巩固通路；new_goal→前瞻事件框架（低基线激活驻留，论文 §5.2 目标机制）；
- 检验（提纲十四用）：任何一条反思，三个月后必须能回答"它改变了哪条边/哪个节点"——答不出即该反思无效，反思模板需带"预期落点"字段。

### 7.7 Soft forgetting（图内遗忘）

- 节点可及性 = f(last_access, 权重)：长期未激活节点权重按曲线缓降（数据保留）；
- episodic 事件的 论元 实体不衰减（共享实体是结构骨架），事件节点本身衰减；
- 被再激活即恢复——"想起来"与"想不起来"成为图的可观测状态。

## 八、稳定性约束（论文 §8.9 三预警的完整对应）

| 预警 | V2 落实 |
|---|---|
| 枢纽节点→激活过度集中 | 保留 inter_decay_floor（参数节点化后由状态调制）；新增出度归一已有；Hebbian 的 w 上限防枢纽边权独大 |
| 边权更新无约束→路径锁定 | Hebbian ε 极小 + w 上限 + 无激活弱化通道 + disposition 的 REMOVE_BELOW 清除机制 |
| 参数调制→非平稳性 | clip 上下界 + 每轮 Δp 平滑 + 参数漂移日志告警（§7.2） |

## 九、V2 验收判据（对应提纲十四）

1. **三问审计通过**：抽查任意行为——决策权在图（行为竞争）、状态在图（无 dict）、删掉该机制后行为可由动力学解释；
2. **边界测试通过**："我终于把 FAS 跑起来了。" 产生非平凡回应，且回应要点可回溯到激活路径（language_arch §四 全链路）；
3. **人格通路产出**：运行 N 周后 倾向: 节点数 > 0 且有 candidate→stable 实例（当前为 0）；
4. **Hebbian 可证**：同一对话主题的边权随使用单调上升，且 w 值历史可追溯；
5. **豁免通道为零**：代码中不存在"强制生成/强制过阈值/直接替代"类分支（grep 可验）；
6. **图的组成健康**：回答记录类节点占比归零（迁日志），倾向/信念/偏好节点非零（growth 脚本可验）；
7. **回归红线**：事件框架、扩散、Self 子图、disposition 结构零破坏（现有 API 行为不变）。
