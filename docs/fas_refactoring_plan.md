## DO NOT IMPLEMENT（明确禁止清单）

| # | 禁止项 | 理由 |
|---|---|---|
| ✗1 | 强化静态人设 prompt（更多身份/性格/风格规则） | 与人格涌现直接对抗；P1-6 已把人设改为图状态快照 |
| ✗2 | 任何新的行为 if-else / 豁免通道（"某类输入直接生成/跳过竞争"） | P1-1 刚清零，再加一条竞争就多一个漏洞 |
| ✗3 | 图内做完整 NL 解析（句法树节点、词性标注节点、词表节点） | 违背"原子化的是认知表示"（language_arch §二）；解析归语言层 |
| ✗4 | 图谱直接生成自然语言（模板拼接器/语法规则） | 图终止于"说什么"，"怎么说"归语言层 |
| ✗5 | 让 LLM 新增任何"产出即终局"的决策职能 | 违背原则四；LLM 产出必须是候选/结构 |
| ✗6 | 新增硬编码链条/剧本边（"X 之后好奇 Y"类） | CURIOSITY_CHAIN 的教训：剧本替代学习 |
| ✗7 | 复合巨型节点（把对话轮/会话/人格整体建成单节点） | 原子性红线；轮次归日志，人格归倾向边 |
| ✗8 | 扩充情绪/行为关键词表作为主信号 | 词表是天花板（38 词人格）；信号源升级走图内共振+embedding |
| ✗9 | 为"看起来像人"加拟人规则（礼貌脚本、安慰模板、语气词规则） | demo 式智能；拟人感应从经历沉淀（unwanted §5.3/§8） |
| ✗10 | 删除"论文里没有"的涌现机制（焦点指针/短语表/UnknownObject 联动） | 原则六：它们是愿景的活证据 |
| ✗11 | 保留机制仅仅因为"已经实现" | 本审计的元原则；保留判据=三问审计（vision §五） |

## 执行纪律

1. **每个任务独立提交**，提交信息标注任务号（如 `P0-2: 删除 CURIOSITY_CHAIN 剧本边`），便于回滚；
2. **P1 开工前**：全量备份 data/runtime_graph.json；写 growth 审计脚本（节点类型分布统计）作为基线；
3. **P1-1 切换日**：行为竞争日志全开（记录各行为节点激活/偏置/裁决），至少观察 20 轮真实对话再评估；
4. **回归红线**：每个任务完成后跑既有 API 行为对比（事件框架写入、扩散 Top-k、chat_log 记录不得回归）；
5. **不验证不宣称**：每个"完成"都以验证列的判据为准，不满足即回滚或降级为未完成。
