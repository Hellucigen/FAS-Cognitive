# FAS 机制审计总表（fas_mechanism_audit.md）

> 认知架构重评估 · 文档 2/7
> 逐机制审计：当前实现 → 原始意图 → 来源 → 认知角色 → 图表示 → LLM 依赖 → 涌现潜力 → 神经科学灵感 → Keep 判定。
> 来源四分类：**最初设计**（2025 论文原文）/ **后续设计**（2026 开发期主动加入）/ **工程补丁**（让系统跑起来的无认知含义修补）/ **LLM 需求**（因使用 LLM 而必需的防线）。
> Keep 三值：保留（机制与愿景一致，继续）/ 修改（方向对，实现违背原则，需重构）/ 删除（违反原则或无认知含义，移除）。
> 判定依据 = fas_original_vision.md §5 的三个判定问题（决策权在图还是代码？状态在图里还是图外？删掉后行为能否由动力学解释？）。

## 1. 核心动力学层

### 1.1 激活扩散（activation diffusion）

| 维度 | 内容 |
|---|---|
| 当前实现 | diffusion_engine.py：`a(v,t+1)=(1-λ)a(v,t)+Σ a(u)·w·β/|N⁺(u)|`，fire-once 防回灌，能量守恒钳制，边激活 boost `1+edge.activation*0.6`，空间/类别感知增益 |
| 原始意图 | 论文 §5.1 同一公式族；关系语义同步激活（§5.1.2 实现为边激活提升，基本对应） |
| 来源 | **最初设计** |
| 认知角色 | 全系统唯一动力源：注意、联想、候选行为都应由它涌现 |
| 图表示 | 节点 activation / 边 activation 运行时字段（论文 ẇe 的对应物） |
| LLM 依赖 | 无 |
| 涌现潜力 | 极高——一切待涌现机制的地基 |
| 神经科学 | Collins & Loftus 扩散激活（1975） |
| **Keep** | **保留**（核心中的核心） |
| 理由 | 实现忠实于论文，且 fire-once/能量守恒是健康的工程补丁。问题全部在**上游注入与下游裁决**不在扩散本身（见 §5.2、unwanted §7） |

### 1.2 注意聚焦 / Top-k

| 维度 | 内容 |
|---|---|
| 当前实现 | `get_topk(k=20)` 按激活排序；k 静态来自 config |
| 原始意图 | §5.1.4：Top-k = 工作记忆容量的有限性，**k 应由图内参数节点受情绪调制** |
| 来源 | 最初设计（但动态调制部分未实现） |
| 认知角色 | 认知焦点候选集；LLM 上下文的知识依据 |
| 图表示 | 激活值本身 |
| LLM 依赖 | 无 |
| 涌现潜力 | 中（取决于参数节点化） |
| 神经科学 | Cowan 魔法数 4、工作记忆容量 |
| **Keep** | **修改** |
| 理由 | 机制在，但"注意容量受状态调制"缺失（config["k_top"] 静态）。V2 应把 k/θ/λ 参数节点化（论文 §3.3 p(t) 公式） |

### 1.3 衰减机制

| 维度 | 内容 |
|---|---|
| 当前实现 | 三层：扩散内 λ=0.05；回合间 inter_round_decay=0.4；激活地板 inter_decay_floor=0.5（低于即归零）；启动时全图激活归零 |
| 原始意图 | 论文只有 λ。回合间衰减与地板是纯工程发明 |
| 来源 | λ=最初设计；回合间衰减/地板=**工程补丁** |
| 认知角色 | 防噪声跨轮累积；地板截断无关节点传播 |
| 图表示 | 激活值 |
| LLM 依赖 | 无 |
| 涌现潜力 | 低（但地板参数若参数节点化可成为"注意力广度"的状态变量） |
| 神经科学 | 注意资源衰退（§5.1.1 λ 的动机） |
| **Keep** | **保留**（工程补丁部分保留但记为待参数节点化） |
| 理由 | 0.5 的地板很粗暴（等价于"只有上一轮直接点燃的节点能活过回合间隙"），却确实治住了枢纽噪声。先保留，参数节点化后由情绪调制 |

### 1.4 graph_space（认知空间）

| 维度 | 内容 |
|---|---|

| 原始意图 | 论文只有 label 级区分（declarative-semantic/episodic/procedural）；空间化+分区传播规则是 Refactor 0.1 的后续设计 |
| 来源 | **后续设计** |
| 认知角色 | 让自传/情绪/元认知信号与事实知识以不同动力学传播（self 空间衰减少、cognitive 空间增益高） |
| 图表示 | Node.graph_space |
| LLM 依赖 | 无 |
| 涌现潜力 | 高——分区动力学是"情绪调制全图"的可行前置 |

| **Keep** | **保留** |
| 理由 | 数据验证：458 节点全部有空间归属（semantic 320/episodic 81/cognitive 34/self 23），迁移债务已清。机制中性且可扩展 |

## 2. 记忆层

### 2.1 事件框架（event framework）

| 维度 | 内容 |
|---|---|
| 当前实现 | app.py `_wire_event_structure`：事件枢纽节点（episodic 空间）+ 涉及/参与者/发生时间/引发 槽位边 + 时间锚节点 + `时间顺序` 父子链 + 焦点指针。MEMORY_EXTRACT 模板约束 LLM 按此输出 |
| 原始意图 | 论文 §3.2-3.4 逐条对应（中心节点+嵌套子图+论元槽位+映射边+层级化事件） |
| 来源 | **最初设计**（2026-08-14 完成迁移落地） |
| 认知角色 | 经验的组织单元；"何时何地发生了什么"的结构化保持 |
| 图表示 | 事件节点 + 论元边 + 时间顺序边 + 当前焦点事件指针 |
| LLM 依赖 | 高（LLM 产出事件草稿；模板 7 规则+代码归一防线） |
| 涌现潜力 | 高——跨事件共享实体→经验网络→类比回忆的路径已经打开 |
| 神经科学 | 事件分割理论（Zacks）、脚本理论（Schank） |
| **Keep** | **保留**（当前系统最健康的大机制） |
| 理由 | 数据验证：远方之行事件簇完整（参与/涉及/参与者/发生时间/3 个子事件链/焦点指针指向它）。这是"论文设计→实现落地→数据可证"的正面标本 |

### 2.2 焦点事件指针

| 维度 | 内容 |
|---|---|
| 当前实现 | `当前焦点事件` 节点 -[指向]→ 头部事件；启动时引导到最新无父事件；提取时注入【进行中的事件】上下文 |
| 原始意图 | 论文 §3.3 自认知子图含"当前认知焦点事件框架"——指针式实现是自创 |
| 来源 | **后续设计**（自创，但忠实于论文概念） |

| LLM 依赖 | 低 |
| 涌现潜力 | 中——若指针本身参与扩散，可成为"心理时间线上当下"的位置感 |
| 神经科学 | 心理时间线中的"现在"（working self, Conway） |
| **Keep** | **保留** |
| 理由 | 万物皆图合规（指针是图节点）、LLM 依赖低、解决了真实问题 |

### 2.3 情节缓冲器（episodic buffer）

| 维度 | 内容 |
|---|---|
| 当前实现 | episodic_buffer.py：内存 List[EpisodicExperience]（容量 100，importance/access 淘汰，晋升阈值 access≥3/importance≥0.7/activation≥5）；R1 扩展后还承载表达事件（add_expression/annotate_expression） |
| 原始意图 | 论文 §4.1：缓冲器是**多模态对齐整合中枢**（视觉坐标+听觉方向→统一中间表示→LLM 归纳为事件框架），窗口由图内参数调节 |
| 来源 | 名字与最初设计同源；**实现完全走样** |
| 认知角色 | 名义上是工作记忆；实际是 (a) 记忆草稿暂存 (b) 行为倾向的证据队列 (c) 晋升判定器 |
| 图表示 | **无——纯 Python 对象，违反万物皆图** |
| LLM 依赖 | 无 |
| 涌现潜力 | 低（当前形态） |
| 神经科学 | Baddeley 情节缓冲器（论文引用 [1]） |
| **Keep** | **修改**（结构性重构） |
| 理由 | 三重问题：①状态在图外（unwanted §3）；②"晋升"与图内 `_auto_consolidate` 双轨冗余；③论文的跨模态整合职责完全缺失。短期可保留为草稿队列，长期其职责应归还图（激活值即工作记忆状态） |

### 2.4 记忆巩固（consolidation）

| 维度 | 内容 |
|---|---|
| 当前实现 | 双轨：`_auto_consolidate_curiosity_knowledge`（问答后自动入图，跳过审批）+ `/api/memory/approve`（人工审批）；buffer 晋升只是打标记 |
| 原始意图 | §6.1/§6.3：知识写入含来源置信度与重复验证增量增强；结果回写为事件 |
| 来源 | 自动巩固=工程补丁（agent 代管模式下审批等于数据丢失）；审批路径=后续设计 |
| 认知角色 | 草稿→长期记忆的转化 |
| 图表示 | 直接加节点/边（带 taught_by_user/source 属性） |
| LLM 依赖 | 高（MEMORY_EXTRACT） |
| 涌现潜力 | 中 |
| 神经科学 | 海马→皮层记忆巩固 |
| **Keep** | **修改** |
| 理由 | 自动巩固解决真实问题（无人值守场景），但**重复验证增量增强（δ 增量）没实现**——同一条边反复被抽取只取 max 不累积，学习信号被浪费。应合并双轨为一条带证据累积的巩固路径 |

### 2.5 记忆衰减 / 遗忘

| 维度 | 内容 |
|---|---|
| 当前实现 | 仅 buffer 内遗忘（importance/access 淘汰）+ 每日偏好衰减 decay_preferences；**图内节点无遗忘机制**（episodic_retention_days=30 配置存在但无消费者） |
| 原始意图 | 论文未明确图内遗忘；buffer 淘汰对应 §4.1 |
| 来源 | 部分最初设计；图内遗忘=**缺失** |
| 认知角色 | 应让长期不被激活的记忆逐渐降低可及性（不是删除而是沉睡） |
| 图表示 | 应作用于 last_access + activation 历史 |
| LLM 依赖 | 无 |
| 涌现潜力 | 高——遗忘曲线+激活回访可自然产生"记忆新近性"效应 |
| 神经科学 | 遗忘曲线、检索诱发遗忘 |
| **Keep** | **修改**（补实现） |
| 理由 | 458 节点尚无紧迫性，但"只进不出"的结构若不解决，噪声问题会随规模恶化。P1 以 last_access 驱动权重衰减（soft forgetting），不删数据 |

| 涌现潜力 | 中 |
| 神经科学 | 自我参照效应 |
| **Keep** | **修改** |
| 理由 | 机制本身合规，但 **self_model 把用户也建模进来了**（`_extract_self_candidates` 把 用户→X 的边当作 FAS 偏好候选、用户是X 当作信念）——自我模型与用户模型混淆（unwanted §3.5）。数据现实：458 节点中 信念:/偏好: 节点数为 0，机制从未产生过实际产出 |

### 2.7 行为倾向 / disposition（Reflection Evolution R2）

| 维度 | 内容 |
|---|---|
| 当前实现 | disposition_store.py：情境:节点 -[激活 w=strength]→ 行为:节点；封闭词表（9 行为×~10 情境）；candidate→stable 晋升（证据≥4、正负比≥3:1、强度≥0.5）；LLM 只提候选，数值代码计算；tendencies 注入 ANSWER_GENERATE |
| 原始意图 | 论文无对应（论文性格=情绪参数调制器）；动机来源于 2026-08 重评估："人格从经历中形成而非 prompt" |
| 来源 | **后续设计** |
| 认知角色 | **当前系统里唯一真正朝"涌现人格"走的机制** |
| 图表示 | self 空间 ✓（强度同步边权 ✓，证据计数在 extra_attrs 可接受） |
| LLM 依赖 | 低（LLM 仅提名，启发式 classify_outcome 打标） |
| 涌现潜力 | **最高**——情境→行为→结果→边权变化，正是用户要求的 经历→激活→强化→稳定倾向 通路 |

| **Keep** | **保留**（重点修复数据通路） |
