## B. 注入文本检查(T3 step-0,seed 0 完整回放;seed 1/2 结构相同)

**C1(FAS-full)**:`结果:tool_missing:stone_pickaxe (act 3.9763)` 出现在
working set 第 7/8 席(高激活),且 gate 额外含 `stone_pickaxe`——
失败证据**显式、醒目、可读**(字符串本身含 "tool_missing")。

**C3(Flat-Store)**:注入 16 行全部为高极性填充事实
(gather_dirt、explore_north×4 及其 obs 实体 oak_log/oak_planks)。
**tool_missing 事实完全不在文本中**——预注册规则
(polarity 降序 → 失败排最后;8 事实×2 行截断)将其结构性挤出。

**C4(Graph-NoActivation)**:注入含 `物品:iron_ore (act 0.5)` 但**不含**
`结果:tool_missing:...`——失败结果节点距 obs 实体 2 跳
(iron_ore → 动作:gather_iron_ore → 结果:tool_missing),1 跳规则
不可达。注意:C4 的图由 make_fas("full") 构建,**ef_context=True,
负极性边在图里存在**——信息在存储中,被选择规则丢弃。

失败信息呈现对比:C1=显式失败串+高激活位;C3=缺失;C4=缺失
(其图内有,未序列化)。三者不满足"呈现等价"。

## C. 为什么 C3/C4 比 reset 更差(7.7)

数据可确认的事实:C3/C4 的注入比 C2 多出 iron/oak 相关提及
(C4 显式含 物品:iron_ore;C3 含 8 行 oak_planks/oak_log 重复),
且均无任何失败标记;C2 的注入同样含 iron_ore(obs 点亮)但内容更短。
候选解释(数据无法完全区分):
1. **无标记启动**:工作集高亮失败动作的客体(iron_ore)却不带失败
   信号,构成对 gather_iron_ore 的启动,而完全无内容(C2 较短)
   时模型更可能偶然转向;
2. **长度/噪声**:C3 的 16 行重复填充使模型更倾向选择菜单首位
   (gather_iron_ore 在 obs 排序中靠前);
3. C2 的"偶然转向"本身方差大(6-10),与 C3/C4 的 0 转向差异
   主要由"从不转向"贡献。
无法区分,列为限制。

## D. 通道等价性判定

**判定:类别 1——失败信息在 C3/C4 中未进入决策(截断/排序/未序列化)
→ 接口/通道问题。** 置信度:高。
证据:①B 节注入文本回放(seed 0 完整;1/2 结构相同);②C3 10/10
seed 恰为 12(纯触顶,零转向);③C4 的失败边存在于其图中但
1 跳规则不可达;④C1 与 C3/C4 的失败信息"呈现"不等价
(等价性检查只核对了事实集合,未核对呈现——见 F)。

**未排除的替代解释**:若给 C3 一个"失败优先"的固定规则、给 C4
一个 2 跳邻接,失败信息进入文本后 C1 是否仍占优——本实验未测。
因此**不能**从 T3 得出"图结构或 spreading activation 有独立贡献";
只能得出"决策时可见的失败证据改变行为"(与 E2/修复实验一致)。
若 C1 优势在等价呈现下消失,则归因于呈现;若仍在,才可谈机制。
