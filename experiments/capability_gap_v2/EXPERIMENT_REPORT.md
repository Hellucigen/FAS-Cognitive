统计:n=10 配对种子;McNemar/Wilcoxon 配对检验;族内 Holm;校正前后 p 并报。

## What FAS can currently do(有实验支持)

1. **把经历变成可复用的关系知识并用于后续决策**(A):经历后闭卷任务 10/10,
   无经历的 fresh-fas 0/10(Holm p=0.0195)。知识确实经由持久图谱交付。
2. **在等成功率下提供远小于原始历史的决策上下文**(K):FAS 状态 923 tokens/run
   vs 全历史(200 事件)13290 tokens/run(≈14×);retrieval 1173。
3. **短程延迟信用**(B,机制层):后果在 90s 归因窗内(≤80s)稳定形成 A→C 关联
   (0/32s:10/10;80s:inventory 10/10)。
4. **机制层能力**(既有+本轮审计):多输入汇聚(JCG 200/200、shared-hub 30/30
   与 84 格优势区)、跨情境再激活、账本/事件框架消费通道——13/13 运行时探针通过。

## What FAS can do but LLM baselines can also do(重要)

- **A**:LLM 直接读 6 行原始历史同样 10/10(p=1.0);retrieval 同样 10/10。
- **K**:所有历史窗口(10..200)成功率与 FAS 无差——在 ≤200 事件的短历史上,
  "lost in the middle" 未出现,压缩不换来性能保护,只换来成本。
- 结论:在**短历史、单目标、可观测**的任务上,持久关系状态没有表现出
  任务成功率层面的额外能力。

## What FAS appears to add(有比较证据的部分)

- **中断目标的自发重拾**(C,P3 闭卷自由相):fas 9/10 vs history 0/10、
  direct 0/10(McNemar p=0.0039)。同一任务、同一菜单、同一模型,
  唯一差异是记忆形式:持久关系状态+需求分析把未完成链推入注意,
  而**读完整个原始历史的 LLM 不会自发回去做**。这是本轮唯一干净的
  Level-3 比较证据,方向为 FAS 优。
- **成本维度的压缩**(K):923 vs 13290 tokens/run,等成功率。
- **可审计性**:上下文构成逐项可溯源(协议性质,非统计主张)。
- 机制层的汇聚/延迟窗/再激活有 LLM 基线没有的可测量对应物,
  但均未桥接到行为优势(见下)。

## Where FAS is currently WORSE than baselines(同样如实)

- **目标修订/止损**(E):工具门槛失败下,history 平均 1.0 次失败即转向
  (10/10,步 1.5),fas 平均 11.1 次失败、8/10 转向且晚(步 5.9),
  direct 从不转向(0/10)。FAS 的上下文没有把"刚刚失败"呈现得足够显著,
  需求分析反而维持目标压力——**持久状态的目标黏性在环境突变时是负债**。
- 注意 C 与 E 是同一枚硬币的两面:同一机制(状态维持)在干扰下是优势
  (重拾),在环境变化下是劣势(不放手)。本轮第一次给出该权衡的成对数据。

## Main architectural bottlenecks(实验驱动,非预设)

1. **归因窗硬上限**:90s 窗+⅔窗资格线 → 长程因果信用分配在现架构内不可得(B)。
2. **机制→行为断层(表示研究已收窄但未完全定位)**:行为层 I 任务上
   FAS 0-2/10 而 LLM 原始历史 10/10(Holm p=0.041)。表示研究(v1.2,30 run):
   扩预算 k=16/32 与富序列化(补 动作→结果 配对+实体共现)均 0/10——
   **"丢结构"与"预算不足"两个假设都被拒绝**。剩余解释:原始流的
   时序叙事形式(逐行 obs|action|result 让模型重演整个情节)本身承载
   计划信息,节点摘要式序列化在格式层面难以替代;修复方向不是格式
   微调,而是消费者设计(叙事式图上下文,或规划器直读图谱不经 LLM)。
3. **自我模型"写而不读"**(F v6):目标→Self 图同步经生产入口与遥测验证
   真实落图(5/5/5),但 current_goal() 在生产代码中零读取者——行为惰性
   是消费路径缺失(与 U2 同构),不是"自我模型无用"的假设检验结果。
4. **序列化开销**:FAS 额外 token 主要是 graph→text 序列化(interface overhead),
   应如此表述而非"推理更贵"(K)。
5. **菜单可见性泄漏配方**(I 的局限):持有原料时 craft_X 自动出现在菜单,
   经历子集隔离因此不彻底(已在 PRECHECK 声明)。

## 最终回答(任务书 §31)

> 当一个强大的 LLM 已经可以读取历史、调用工具、分析日志时,
> 一个持续存在的 relational cognitive state 还能提供什么?

在本战役测试的范围内(短历史、单目标、可观测、7 步以内链),答案不是"很少",
而是**一处真实增量、一处真实劣势、其余等效**:

- **增量(C)**:中断目标的自发重拾——读完全部原始历史的 LLM 不会做的事,
  持久关系状态会做(9/10 vs 0/10,Holm p=0.0117)。加上 K 的 ~14× 上下文
  压缩与全程可审计性,这三项构成继续研究 persistent relational cognitive
  state 的实证理由。
- **劣势(E + I)**:环境突变下止损慢于原始历史(11.1 vs 1.0 次失败,
  Holm p=0.0059);行为层多经验汇聚被原始历史流完胜(0/10 vs 10/10,
  Holm p=0.041)——FAS 的上下文序列化丢失了可执行配方结构。
  状态维持与目标黏性是同一机制的两面,本轮给出成对数据。
- **等效与未兑现**:短历史任务成功率(A/K)基线全部追平;长延迟信用(>90s)、
  自我模型行为相关性(检验通道断连)未兑现。
- 净结论:持久关系状态**不是**"更好的记忆"(两个维度上基线更优),
  它是**不同形状的记忆**——在一个基线做不到的维度(自发重拾中断目标)上
  有干净证据,在成本与可审计性上有结构优势;其机制层对象(汇聚、信用窗、
  再激活)值得继续研究,但行为表达层(上下文序列化格式)是当前主要瓶颈。

是否值得继续作为 persistent relational cognitive state 的研究对象:
**值得,但研究问题应重定位**——从"它能否让任务做得更好"转向
"它能否在更长历史/更强噪声/多目标竞争下保持成本与可审计性优势,
以及其机制层现象能否找到行为消费路径"(本轮给出的负面边界正是
下一步的设计约束)。
