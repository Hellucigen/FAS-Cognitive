## 人工核查清单(正式运行前逐项打勾,结果记入 PRECHECK_REPORT.md)
- [ ] LLM-history 拿到的历史是否**足以**完成任务(用 oracle 自测一遍);
- [ ] FAS 上下文是否含有 baseline 拿不到的 ground-truth(如未被经历支持的配方闭包——由 exclude_recipes 保证);
- [ ] 检索条件查询文本与 top-k 与 FAS 上下文预算对齐(k=8);
- [ ] 闭卷门控对全部条件一致(craft 菜单仅当 物品:X 在该条件上下文中出现);
- [ ] Direct 条件确实零记忆(store 不写入);
- [ ] no-diffusion 上下文 activation 字段全 None;no-writeback 测试前图谱中无经历来源边(边计数核对);
- [ ] 练习流逐字节一致(哈希核对,写入 PRECHECK_REPORT)。

## 已知不对称(如实声明)
1. FAS 的图谱含**生产配方闭包播种**(除被排除项):这是生产先验,不是经历;对比条件没有。凡目标配方都被 exclude 的实验(A/I/K),此不对称不涉及任务解;但其它配方闭包仍在 FAS 一侧——在 BASELINE_MATRIX 声明,并在报告中作为 scope 注记。
2. LLM-history 的 token 预算无上限(输入侧),FAS 上下文固定 top-8——这是设计对象本身(压缩价值),不是不公平;token 成本单独拆解(§18)。
